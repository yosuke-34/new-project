# 制作ガイド ── 見開きの酒標帖を作って贈るまで

価格はすべて 2026 年時点の**目安**です。購入前にお店で確認してください。

---

## 0. 完成形

- **A4 横（A4-E）のバインダー**。表紙に和紙の題簽（題名の紙）と、隅に **QR シール**（台紙の検索・印刷ページへ）、背に背表紙
- A4 横のクリアポケットに入った中身
  - 扉 → 使い方 → ラベルの剥がし方 → 全国制覇地図
  - 区分ごとに：中扉 → 目録 → **見開き**（左：ラベル台紙／右：銘板）の並び
  - 巻末に、空のラベル台紙・空の銘板・空のポケット
- 道具箱：フォトコーナー、弱粘着の両面テープ、ラベル剥がしシート、グラシン袋、落款はんこと朱肉
- 一本目のお酒（その造り手の銘板を印刷して、見開きをひとつ空けておく）

## 2. 作り方

### Step 1　検索・印刷ページを公開して、QR を入れる

1. `site/` フォルダは **GitHub Pages**（https://yosuke-34.github.io/new-project/ ）に公開する。`.github/workflows/pages.yml` が、`site/` を変更してプッシュするたびに自動で公開し直す
   - 初回だけ、GitHub のリポジトリの **Settings → Pages → Build and deployment → Source** を「**GitHub Actions**」にして、**Actions** タブで「Deploy site to GitHub Pages」を **Run workflow** する
2. `templates/config.json` の `siteUrl` には公開 URL を入れてあり、扉（`print/01_cover-guide.pdf` の 1 ページ目）と表紙用の QR シール（`print/05_cover-parts.pdf`）に QR コードが入っている
3. 公開されたら、印刷した QR を**スマホで読み取ってページが開くか必ず確かめる**

### Step 2　試し刷り

`print/03_label-sheets.pdf` の 1 ページ目と、検索ページから作った銘板を 1 枚ずつ、**A4 横・倍率 100%**で印刷し、ポケットに入れて見開きにしてみる。

- 左右のページで爪の色と高さがそろうか
- 造り手の名前（楷書）がにじまず読めるか、QR がスマホで読めるか
- 手元の空き瓶のラベルを枠に当てて、大きさを確かめる

### Step 3　本番印刷

| 印刷するもの | 枚数の目安 |
|---|---|
| `01_cover-guide.pdf`（扉・使い方・剥がし方・地図） | 1 部 |
| `02_dividers-index.pdf`（中扉と目録） | 1 部 |
| ラベル台紙（`03_label-sheets.pdf` の区分のページ） | 日本酒 15・ウイスキー 5・ジン 3・ワイン 3・ビール 3 くらい |
| 空の銘板（`04_blank-meiban.pdf`） | 各区分 2〜3 枚（筆ペンで書く用） |
| 造り手名入りの銘板 | 先に埋める分と、贈る一本の分だけ検索ページから |

印刷通販に出す場合は `print/bleed/` の塗り足し付き PDF を使うと、爪の色が紙の端まで出て、閉じたときに小口で区分が分かります。

### Step 4　表紙

1. 題簽（`05_cover-parts.pdf`）を和紙に刷って切り、表紙の左上に貼る
2. 背表紙（`05_cover-parts.pdf` の 2 ページ目）から背幅にいちばん近いものを選び、高さを背に合わせて上下を同じだけ切って、貼るか背のポケットに差し込む
3. QR シールをシール用紙に刷って切り、**表紙の右下の隅**に貼る

### Step 5　組み立て

- ラベル台紙を**前のポケットの裏面**、銘板を**次のポケットの表面**へ（開いて見開きになることを確かめながら）
- 区分の順は 壱 日本酒 → 弐 ウイスキー → 参 ジン → 肆 ワイン → 伍 ビール。各区分は 中扉 → 目録 → 見開き
- 巻末に空のポケット・空の台紙

### Step 6　最初の数本を埋めておく

白紙のアルバムより、少し埋まっている方が続けたくなります。

- 一緒に呑んだことがある銘柄や、相手の地元の酒を 2〜3 本。ラベルを剥がして乾かす（2 日みる）
- 検索ページで造り手を探して銘板を印刷し、見開きに。目録に記入、地図を塗り、道しるべに落款を押す
- **贈る一本の造り手の銘板も印刷して、空の見開きを用意しておく**（受け取った日に最初の一本が埋められる）

### Step 7　包む

道具箱・帖・一本目のお酒を風呂敷で一緒に包む。
