# 制作ガイド ── 酒標帖を作って贈るまで

このガイドの通りに進めれば、誕生日プレゼントとして渡せる仕上がりになります。
価格はすべて 2026 年時点の**目安**です。お店や時期によって変わるので、購入前に確認してください。

---

## 0. 完成形

- A4 タテのバインダー（布張りや革の表紙に、和紙の**題簽**＝題名の紙と**背ラベル**）
- クリアポケットに入った中身
  - 扉 → 贈る言葉 → 使い方 → ラベルの剥がし方
  - 全国制覇地図 → 産地索引 → 目録（No.001〜100）
  - 中扉 ×7 と、区分ごとの台紙 計 40 枚前後（うち 2〜3 枚は記入済み）
  - ワイド台紙（A3 二つ折り）×2〜3 枚
- 道具箱：フォトコーナー、弱粘着の両面テープ、ラベル剥がしシート、グラシン袋、落款はんこと朱肉
- 一本目のお酒（台紙の No. をひとつ空けておく）

## 3. 作り方

### Step 1　データを用意する

`print/` の PDF はそのまま印刷できます（名前欄は空欄＝手書き用）。
名前を印字したい場合は README の「名前を入れてデータを作り直す」に従って `templates/config.json` を書き換えて生成し直します。
**名前は筆ペンで手書き**するのも、贈り物としてはむしろ温かみが出ておすすめです。

### Step 2　試し刷り（必ずやる）

1. `04_sheet_3_chubu.pdf` の 1〜2 ページだけを、**倍率 100%（実際のサイズ）・両面・長辺とじ**で 1 枚印刷する。
2. 表の右端と裏の左端に、同じ高さで緑の爪が出ているか確認する（表裏の上下が逆なら「短辺とじ」になっている）。
3. クリアポケットに入れてバインダーに綴じ、爪が小口側に来ているか、No. 欄が隠れないかを確認する。

> 両面印刷できないプリンターの場合：奇数ページだけ印刷 → 紙の向きを変えずに裏返して給紙 → 偶数ページを印刷。最初の 1 枚で向きを確かめてから残りを刷る。

### Step 3　本番印刷

**台紙の枚数配分の例（計 40 枚）**

| 区分 | 枚数 | 考え方 |
|---|---|---|
| 相手の地元・好きな酒どころの区分 | 8 | 一番増える区分を厚めに |
| その他の国内 5 区分 | 各 4（計 20） | PDF を 1 部ずつ |
| 漆 海外 | 4 | ウイスキー好きなら増やす |
| 共通（爪なし） | 8 | 区分が決まらない時用。インデックスシールを貼って使う |

各 PDF には台紙が 4 枚（8 ページ）入っているので、8 枚欲しい区分は 2 部印刷します。

- `01_cover-guide.pdf`・`02_index-map.pdf`・`03_dividers.pdf` は**片面**で OK。
- `05_wide-sheet_A3.pdf` は A3。家庭用プリンターが A4 までなら**コンビニのネットプリント**（A3 対応）を使う。
- `06_cover-parts.pdf` は**和紙**に印刷。

### Step 4　表紙を仕上げる

1. 和紙に印刷した**題簽**を、外側の細い線に沿ってカッターで切る。
2. 表紙の**左上**（上端・左端から 10〜15mm）に貼る。和本と同じ位置で、一気に「本」らしくなる。全面に両面テープかスプレーのりを使い、端が浮かないようにする。
3. **背ラベル**はバインダーの背幅に一番近いもの（25／35／45mm）を選び、幅を背に合わせて左右を切って貼る。
4. 手軽プランでは、扉の落款を印刷のまま使う。おすすめプラン以上では、題簽の下や扉に**本物の落款を押す**と格が上がる。

### Step 5　組み立てる

README の「構成」の順にポケットへ入れて綴じます。

- 台紙は**表面が手前（右ページ）**になるように入れる（ページをめくると裏面が左ページに来る）。
- 中扉は各区分の先頭。中扉の後ろに、その区分の台紙を数枚ずつ。
- 巻末に空のポケットを 5〜10 枚と、ワイド台紙を入れておく。

### Step 6　最初の数本を埋めておく（いちばん大事）

白紙のアルバムより、**少し埋まっている方が続けたくなる**ものです。贈る前に 2〜3 本ぶんを埋めておきましょう。

- **思い出の一本** … 一緒に呑んだことがある銘柄、相手の地元の酒。もう一度買って呑み、ラベルを剥がす。
- **記録欄は自分の視点で** … 「一緒に」欄に相手の名前、メモ欄に当時のエピソード。
- **目録に記入、地図を塗る、道しるべ「初めの一県」に落款を押す。**
- 剥がす → 乾かす → 重しでのばすのに **2 日**はかかるので、余裕をもって。

そして**一本目のお酒のために次の No. を空けておき**、瓶に「No.00X はこの一本で」と書いたタグを掛けて一緒に渡します。帖を開いた瞬間に「最初にやること」があると、その日のうちに使い始めてもらえます。

### Step 7　贈る言葉

扉の次のページは縦書きの便箋になっています。筆ペンで、一言でも。

### Step 8　包む

- 道具類は小箱にまとめ、「道具箱」と書いた題簽の余りを貼る。
- 帖・道具箱・お酒を風呂敷で包む。お酒は「瓶包み」、帖は「お使い包み」で一緒に。

## 4. 一部を発注する

### 台紙・扉一式の印刷（おすすめ）

- `print/bleed/` の PDF を**印刷通販（ネット印刷）**に入稿します。仕上がり A4、**塗り足し 3mm 付き（216×303mm）**、フォント埋め込み済みです。
- 用紙は **マットコート紙 135〜180kg 程度**、カラー両面（台紙）／片面（扉・索引・中扉）。
- 爪（色帯）が紙の端まで印刷されるので、**閉じたときに小口に区分の色が見える**ようになります。家庭用プリンターでは出せない、発注ならではの仕上がりです。
- 納期は 3〜7 営業日が目安。初めての印刷所なら、入稿前にデータチェックの有無を確認しておくと安心です。

### 表紙

| やりたいこと | 探し方（検索語） |
|---|---|
| フルカラーで表紙を印刷したバインダーを 1 冊だけ | 「オリジナル バインダー 印刷 1冊から」 |
| 革のバインダーに名前を刻印 | ハンドメイドマーケット（Creema、minne など）で「A4 バインダー 革 名入れ」 |
| 布表紙にタイトルを箔押し | 「箔押し 名入れ 持ち込み」「箔押し 1個から」 |

### 落款はんこ

- `06_cover-parts.pdf` の落款を原稿として、はんこ店に**データ入稿**します（「落款印 データ入稿」「蔵書印 オーダー」で探せます）。
- サイズは 15mm 角か 21mm 角が使いやすい。落款の文字は `sealText` で変えられるので、相手の名前の一字を入れても良い。
- 納期が 1〜3 週間の店もあるので、**最初に発注**しておく。

## 5. 上級編：表紙を自作する（クロス装バインダー）

市販のバインダーで満足できない場合の選択肢です。製本の経験がなくても、丁寧にやれば 1 日で作れます。

**材料**：グレーボード（2mm 厚）、ブッククロス（布）、製本用ボンド、バインダー用リング金具（単体で売られているもの）と取り付け用のリベット、見返し用の紙（和紙や色上質紙）

1. グレーボードを **表板・裏板（各 225×310mm 程度）と背板（金具の幅＋α）** に切る。
2. ブッククロスの裏に、表板・背板・裏板を **板の間を 7mm ずつ空けて** 並べてボンドで貼る（この隙間が開き具合を決める）。
3. 周囲に 15mm の折り代を残してクロスを切り、四隅を斜めに落としてから内側に折り込んで貼る。
4. 背板の内側にリング金具を当て、穴を開けてリベットで留める（金具はポケットの穴と合うものを）。
5. 内側に見返し紙を貼って板とクロスの端を隠し、重しをして一晩乾かす。
6. 題簽と背ラベルを貼り、可能なら箔押しを。

## 6. スケジュール（誕生日から逆算）

| 時期 | やること |
|---|---|
| **4 週間前** | プランを決める。**落款はんこを発注**。バインダー・ポケット・道具を注文。表紙を発注するならここで。 |
| **3 週間前** | 名前を入れるなら `config.json` を編集して生成。**試し刷り**。問題なければ印刷通販に入稿（または家で本番印刷）。 |
| **2 週間前** | 先に埋める 2〜3 本を呑み、ラベルを剥がして乾かす・のばす。一本目として渡すお酒を選ぶ。 |
| **1 週間前** | 題簽・背ラベルを貼る。組み立て。記録の記入、地図塗り、落款押し。贈る言葉を書く。 |
| **前日** | 最終チェック、包む。お酒は冷蔵が必要なら当日まで冷やしておく。 |
